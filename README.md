# SonyLanguageUnlock · Sony语言解锁

中文 | [English](README.en.md)

面向日版 Sony 相机的 Windows 桌面语言工具。程序内可切换中文 / English；电脑端界面语言与相机中文解锁选项互相独立。

**当前写入支持仅限 ILCE-7CM2、固件 2.01、日版 J1。** 更名不代表已经验证全部 Sony 机型。检测模块可尝试查询其他 Sony MSC 相机的型号和固件；不同机型的检测兼容性也需要实机核验。识别成功不等于允许写入。

## 使用

完整解压 Windows 发行包，保留 `_internal` 文件夹，运行 `SonyLanguageUnlock.exe`。无需安装 Python。

**0.3.2 起，普通 MSC 和服务接口统一使用 WinUSB。** 首次使用先按下方“Zadig 驱动设置”配置；从 0.3.1 升级时，也需要将普通接口原来的 libusb-win32 改为 WinUSB。

- 相机开机，USB 选择“大容量存储 / MSC”，关闭其他相机软件，只连接一台相机。点击“检测设备”，等待显示型号与固件版本。
- 默认不解锁中文：开启其他语言并关闭简体、繁体中文，不读取固件包或字体。
- 需要中文：勾选“解锁中文”，选择自己的官方 `BODYDATA.DAT`。界面显示包内型号和版本；“更换固件包…”可选择另一个文件。**这里不刷机、不安装或更新相机固件。**
- 固件包型号或版本与设备不一致时，程序提示并阻止开始；选择中文但没有有效固件包时会提示先选择。当前写入只接受已验证的官方 ILCE-7CM2 / 2.01 包。
- 点击“开始解锁”。程序重新读取设备信息、绑定同一机身，再执行语言配置和所选字体恢复；运行中保持连接和供电。
- 完成后断开 USB，关机再开机，滚动语言菜单并实际检查所选语言。确认正常后重新连接 MSC，勾选重启确认，再点击“重启后只读核对”。

## Zadig 驱动设置

以下 USB ID 已在 ILCE-7CM2 上核对，不代表所有 Sony 机型都使用相同 ID。

| 相机模式 | USB ID | 0.3.2 所需驱动 |
|---|---|---|
| 普通大容量存储 MSC | `054C:0E8A` | WinUSB |
| 服务连接 | `054C:0336` | WinUSB |

先关闭 SonyLanguageUnlock 和其他相机工具，仅连接目标相机。相机开机并选择“大容量存储 / MSC”。记录原驱动名称，便于恢复。

1. 从 [Zadig 官网](https://zadig.akeo.ie/)下载，以管理员身份运行。
2. 勾选 **Options → List All Devices**，选中相机，核对 **USB ID = `054C 0E8A`**；不要仅凭设备名称判断。
3. 右侧选择 **WinUSB**，点击 **Replace Driver / Install Driver**，等待完成。左侧当前驱动应显示 WinUSB。
4. 服务接口 `054C 0336` 出现时，用同样方法绑定 WinUSB；已显示 WinUSB 时无需重复安装。不要选择 USB Hub、复合设备父节点或其他 ID。

上述菜单与绑定操作依据 [Zadig 官方指南](https://github.com/pbatard/libwdi/wiki/Zadig)。安装可能出现管理员或驱动信任提示；安装器可能为设备驱动包创建证书，不能把此过程称为“完全不涉及证书”。本程序自身不安装驱动或导入证书。

**只有 `0E8A`、没有 `0336` 时：**这是普通 MSC 状态。选择大容量存储本身不会出现服务接口，程序检测时才会请求切换。首次尚未安装服务驱动，可在 Zadig 的高级模式中通过 **Device → Create New Device**，为 VID `054C`、PID `0336` 预装 WinUSB；不要虚构 MI（接口号）。官方指南说明该功能可为尚未连接的设备准备驱动，待对应接口出现时使用。若已有错误驱动，仍需在该接口出现后核对并替换。此预装路径尚未在本项目的干净 Windows 环境实测。

完成后退出 Zadig，断开 USB、将相机关机再开机，重新连接 MSC。运行 **0.3.2 或更新版**，点击“检测设备”；以型号、固件版本显示正确且相机恢复普通 USB 为通过。旧 0.3.1 的普通接口使用 libusb0，不用于验证这套双 WinUSB 配置。

**需要恢复读卡／官方软件访问时：**替换 MSC 驱动可能影响这些功能。可在设备管理器中核对相机硬件 ID 后尝试“回退驱动程序”；若不可用，按 [Zadig 官方恢复说明](https://github.com/pbatard/libwdi/wiki/FAQ#help-zadig-replaced-the-driver-for-the-wrong-device-how-do-i-restore-it) 卸载该设备及对应替换驱动包后重连，让 Windows 重新匹配原驱动。恢复 MSC 原驱动后，本工具可能需要再次绑定 WinUSB。

## 校验和写入范围

支持的语言配置为 35 个属性；不选中文时启用其余 33 项并关闭两项中文。中文模式先解除所需属性保护、启用语言、恢复保护，再补齐两份中文 LTT 和图标 TTF；已有且字节一致的文件跳过，已有但不一致的文件停止覆盖。

## 记录与失败处理

点击“打开本机记录”查看日志。新安装默认使用 `%LOCALAPPDATA%/SonyLanguageUnlock`。若存在旧版 `%LOCALAPPDATA%/A7C2LanguageTool`，继续使用旧目录，保留未完成操作标记，不因更名绕过重试限制。

每次写入只尝试一次；超时或读回失败时保留记录并停止。不要删除待核对记录来反复重试，也不要公开包含机身配置快照的记录目录。确认重启、菜单正常后再执行只读核对。重新启动程序后可直接执行已有操作的只读核对，无须再次选择固件包。

Windows 两个相机接口统一绑定 WinUSB，程序使用随包 libusb1，不依赖系统 `libusb0.dll`，不自动切换到 libusb-win32 后端。程序不安装驱动、不导入证书、不在命令失败后换后端重发。设备模式为普通 MSC `054C:0E8A`、服务连接 `054C:0336`。

## 验证状态

0.3.2 的双 WinUSB 只读检测已在 ILCE-7CM2 / 2.01 实机通过：读取型号、版本和机身身份，自动恢复普通 USB，配置及文件写入次数为零。61 项离线测试通过。**完整 GUI 解锁写入流程尚未重新验证，单次检测成功也不代表所有连接状态均可靠。** 此前人工恢复流程成功由用户报告。升级固件后是否要重复操作仍未测试。英文界面覆盖操作控件、流程提示和常规进度；底层库或未映射的技术错误保留原文并注明 Technical details。


测试禁止 USB 枚举；设备查询使用模拟传输，配置使用合成 BK4。最终构建见 `dist/`。固件、字体、构建缓存与机身私有快照不进入源代码发行包。详见 [验证记录](VALIDATION.md)、[字体比较](FONT_COMPARISON.md)、[第三方来源](THIRD_PARTY.md) 和 [GitHub 上传教学](GITHUB_UPLOAD.md)。
